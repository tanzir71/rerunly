## Description

Rerunly is an AI browser agent that lets you save and rerun browser tasks using your choice of OpenRouter or local LM Studio models.

Unlike a blind macro, Rerunly checks its work. It captures the visible result after every browser action, compares what changed, combines that view with structured page evidence, and asks the selected vision model to verify the outcome before continuing.

Features:

- Visually verified browser task automation
- OpenRouter and local LM Studio model support
- Reusable tasks launched manually with Play
- Encrypted local vault for API keys and protected task variables
- Guarded site access and sensitive-action approvals
- Multi-tab navigation with a visible, interruptible run timeline
- Local redaction of recognized sensitive input regions
- No Rerunly account, backend, telemetry, or cloud sync

Rerunly requires a model that supports both image input and tool calling. Visual page content is sent directly to the provider you configure. Review the privacy disclosure before starting a run.
